## Files

- welcome.py: Defines a welcome() function that returns a greeting for a given name.

## Reflection

The greet() function was the hardest to write because it uses a default parameter. I had to understand how Python uses "Hello" automatically when no greeting is provided and how a different greeting can be passed in.
